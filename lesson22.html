Access Modifiers

What are Access Modifiers?

Access modifiers are Java keywords that control where classes, variables, methods, and constructors can be accessed.

Simple idea: Access modifiers act like security levels for your code. They decide who can use a particular class or member.

Four Access Levels

Modifier Same Class Same Package Subclass Other Package
private ✓ ✗ ✗ ✗
default ✓ ✓ Limited ✗
protected ✓ ✓ ✓ Limited
public ✓ ✓ ✓ ✓

private

A private member can be accessed only inside the same class. 

class Student {

    private String name;

    private void display() {
        System.out.println(name);
    }
}
Remember: Private members are hidden from other classes.

public

A public member can be accessed from anywhere where the class itself is accessible. 

public class Student {

    public void display() {
        System.out.println(
            "Student"
        );
    }
}

Default Access

When no access modifier is written, Java gives the member package-private or default access. 

class Student {

    String name;

    void display() {
        System.out.println(name);
    }
}

Default members can be accessed by classes in the same package.

protected

A protected member can be accessed inside the same package and by subclasses in other packages. 

class Person {

    protected String name;

    protected void display() {
        System.out.println(name);
    }
}

Example of private Access

A common use of private is encapsulation. Data is hidden and accessed through public methods. 

class BankAccount {

    private double balance = 5000;

    public double getBalance() {
        return balance;
    }
}

public class Main {

    public static void main(String[] args) {

        BankAccount account =
            new BankAccount();

        System.out.println(account.getBalance());
    }
}

protected with Inheritance

Protected members are especially useful when working with inheritance. 

class Animal {

    protected String name =
        "Dog";
}

class Dog extends Animal {

    void showName() {
        System.out.println(name);
    }
}

public class Main {

    public static void main(String[] args) {

        Dog dog =
            new Dog();

        dog.showName();
    }
}

Access Modifiers for Classes

Top-level classes can normally use only public or default access. 

public class Student {
}

class Course {
}
Important: A top-level class cannot be declared private or protected.

Access Modifier Comparison

Modifier Visibility Common Use
private Same class only Hide internal data
default Same package Package-level functionality
protected Same package + subclasses Inheritance
public Everywhere Public API / accessible methods

Access Modifiers & Encapsulation

Access modifiers are strongly connected to encapsulation.

Usually, important data is kept private and accessed through methods. 

private double salary;

public double getSalary() {
    return salary;
}

Best Practices

  • Keep fields private whenever possible.
  • Expose only what other classes need.
  • Use public methods carefully.
  • Use protected mainly when inheritance requires it.
  • Use default access for package-specific functionality.

Lesson Summary

Access modifiers control visibility and protect the internal structure of Java classes.

  • private → same class only.
  • default → same package.
  • protected → same package and subclasses.
  • public → accessible from anywhere.
  • Access modifiers are important for encapsulation.
