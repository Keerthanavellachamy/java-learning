Java Basics — Questions 1–25

1. What is Java?

Answer: Java is a high-level, object-oriented and platform-independent programming language developed by Sun Microsystems.

Interview Tip: Mention Java's platform independence.
2. What are the main features of Java?

Answer: Important features include platform independence, object-oriented programming, robustness, security, multithreading and automatic memory management.

3. Why is Java platform independent?

Answer: Java source code is compiled into bytecode. The bytecode runs on the Java Virtual Machine, allowing the same compiled program to run on different operating systems.

4. What is JVM?

Answer: JVM stands for Java Virtual Machine. It executes Java bytecode and provides the environment required to run Java applications.

5. What is JDK?

Answer: JDK stands for Java Development Kit. It contains tools required to develop, compile and run Java programs.

6. What is JRE?

Answer: JRE stands for Java Runtime Environment. It provides the libraries and JVM required to run Java applications.

7. Difference between JDK, JRE and JVM?

Answer: JVM executes bytecode. JRE provides the environment to run Java applications. JDK contains development tools, JRE and JVM.

8. What is bytecode?

Answer: Bytecode is the intermediate code generated by the Java compiler. It is stored in a .class file and executed by the JVM.

9. What is the main method in Java?

Answer: The main method is the starting point of a standard Java application.

It is commonly written as public static void main(String[] args).

10. What are primitive data types?

Answer: Java has eight primitive data types: byte, short, int, long, float, double, char and boolean.

11. What is a variable?

Answer: A variable is a named memory location used to store data that can be used by a program.

12. What is type casting?

Answer: Type casting is the process of converting one data type into another compatible data type.

13. What is the difference between == and equals()?

Answer: For objects, == generally compares references, while equals() is used to compare logical content when properly overridden.

14. What is a constructor?

Answer: A constructor is a special member of a class used to initialize objects. It has the same name as the class and has no return type.

15. Can a constructor be overloaded?

Answer: Yes. A class can have multiple constructors with different parameter lists.

16. What is the difference between local and instance variables?

Answer: Local variables are declared inside methods or blocks. Instance variables belong to an object and are declared inside a class but outside methods.

17. What is a static variable?

Answer: A static variable belongs to the class rather than individual objects, so it is shared among instances.

18. What is a static method?

Answer: A static method belongs to the class and can be called without creating an object of that class.

19. What is the final keyword?

Answer: The final keyword can be used with variables, methods and classes. A final variable cannot be reassigned, a final method cannot be overridden, and a final class cannot be inherited.

20. What is a package?

Answer: A package is a namespace used to organize related classes and interfaces.

21. What is an import statement?

Answer: The import statement allows a Java program to use classes and interfaces from another package without writing their fully qualified names.

22. What is garbage collection?

Answer: Garbage collection automatically identifies and removes objects that are no longer reachable, helping manage memory.

23. What is an object?

Answer: An object is an instance of a class. It contains state represented by fields and behavior represented by methods.

24. What is a class?

Answer: A class is a blueprint or template used to create objects. It defines fields and methods.

25. Is Java completely object-oriented?

Answer: Java is strongly object-oriented, but it also supports primitive data types, so it is not purely object-oriented.

Object-Oriented Programming — Questions 26–50

26. What is OOP?

Answer: OOP stands for Object-Oriented Programming. It organizes programs around objects and classes.

27. What are the four pillars of OOP?

Answer: Encapsulation, Inheritance, Polymorphism and Abstraction.

28. What is encapsulation?

Answer: Encapsulation combines data and methods inside a class and controls access to the data using access modifiers.

29. What is inheritance?

Answer: Inheritance allows one class to acquire properties and behavior from another class.

30. What is polymorphism?

Answer: Polymorphism means one interface or method name can represent different behaviors.

31. What is abstraction?

Answer: Abstraction hides implementation details and exposes only the necessary functionality.

32. What is method overloading?

Answer: Method overloading means having multiple methods with the same name but different parameter lists.

33. What is method overriding?

Answer: Method overriding occurs when a subclass provides its own implementation of an inherited method.

34. Difference between overloading and overriding?

Answer: Overloading usually occurs within the same class and changes parameters. Overriding occurs between a parent and child class.

35. What is an abstract class?

Answer: An abstract class cannot normally be instantiated and can contain both abstract and concrete methods.

36. What is an interface?

Answer: An interface defines a contract that implementing classes agree to follow.

37. Can a class implement multiple interfaces?

Answer: Yes. A Java class can implement multiple interfaces.

38. Can Java support multiple inheritance using classes?

Answer: Java does not support multiple inheritance of classes, mainly to avoid ambiguity. Multiple interfaces can be implemented.

39. What is super?

Answer: The super keyword refers to members of the immediate parent class.

40. What is this?

Answer: The this keyword refers to the current object.

41. What is composition?

Answer: Composition represents a strong has-a relationship where one object contains another object as part of its structure.

42. What is aggregation?

Answer: Aggregation is a weaker has-a relationship where the contained object can exist independently.

43. What are access modifiers?

Answer: Java provides public, protected, default and private access levels.

44. What is private access?

Answer: A private member can be accessed directly only within the class where it is declared.

45. What is protected access?

Answer: Protected members are accessible within the same package and through inheritance under Java's access rules.

46. Can an abstract class have a constructor?

Answer: Yes. An abstract class can have constructors, which can initialize common state when a subclass object is created.

47. Can an interface have methods with implementation?

Answer: Yes. Modern Java interfaces can contain default and static methods with implementations.

48. What is dynamic method dispatch?

Answer: It is the mechanism where an overridden method is selected at runtime based on the actual object type.

49. What is upcasting?

Answer: Upcasting means referring to a child-class object using a parent-class reference.

50. What is downcasting?

Answer: Downcasting converts a parent reference back to a compatible child reference. It should be done carefully.

Strings & Arrays — Questions 51–65

51. What is String in Java?

Answer: String is a class used to represent a sequence of characters.

52. Why is String immutable?

Answer: Once a String object is created, its content cannot be changed. Operations that appear to modify it create another String object.

53. Difference between String and StringBuilder?

Answer: String is immutable, while StringBuilder is mutable and is useful when many string modifications are required.

54. What is StringBuffer?

Answer: StringBuffer is a mutable character sequence designed with synchronized methods.

55. Difference between StringBuilder and StringBuffer?

Answer: StringBuilder is generally preferred for single-threaded use, while StringBuffer provides synchronized methods.

56. What is the String pool?

Answer: The String pool is a JVM-managed area where string literals can be reused to reduce duplicate objects.

57. What is an array?

Answer: An array is a fixed-size data structure that stores elements of the same type.

58. Can an array store objects?

Answer: Yes. Java arrays can store references to objects.

59. What is a multidimensional array?

Answer: It is an array whose elements can themselves be arrays, such as a two-dimensional array.

60. What is ArrayIndexOutOfBoundsException?

Answer: It occurs when a program tries to access an array using an invalid index.

61. How do you find the length of an array?

Answer: Use the array's length property.

62. How do you find the length of a String?

Answer: Use the length() method.

63. What is charAt()?

Answer: charAt() returns the character at a specified index in a String.

64. What is substring()?

Answer: substring() returns a portion of a String based on specified indexes.

65. How can a String be converted to an array?

Answer: Depending on the requirement, methods such as toCharArray() or split() can be used.

Collections — Questions 66–85

66. What is the Java Collections Framework?

Answer: It is a set of interfaces and classes used to store, retrieve and manipulate groups of objects.

67. What is List?

Answer: List is an ordered collection that can contain duplicate elements.

68. What is ArrayList?

Answer: ArrayList is a resizable-array implementation of the List interface.

69. What is LinkedList?

Answer: LinkedList is a List and Deque implementation based on linked nodes.

70. ArrayList vs LinkedList?

Answer: ArrayList is generally better for frequent indexed access, while LinkedList can be useful for operations involving its linked structure.

71. What is Set?

Answer: Set is a collection that does not allow duplicate elements.

72. What is HashSet?

Answer: HashSet is a Set implementation that uses hashing and does not guarantee insertion order.

73. What is LinkedHashSet?

Answer: LinkedHashSet maintains insertion order while providing Set behavior.

74. What is TreeSet?

Answer: TreeSet is a sorted Set implementation based on a tree structure.

75. What is Map?

Answer: Map stores data as key-value pairs.

76. What is HashMap?

Answer: HashMap is a Map implementation that stores key-value pairs using hashing.

77. HashMap vs Hashtable?

Answer: HashMap is generally unsynchronized and permits a null key and null values, while Hashtable is synchronized and does not permit null keys or values.

78. What is LinkedHashMap?

Answer: LinkedHashMap maintains a predictable iteration order, normally insertion order.

79. What is TreeMap?

Answer: TreeMap stores key-value pairs in sorted key order.

80. What is Iterator?

Answer: Iterator is used to traverse elements of a collection.

81. What is Comparable?

Answer: Comparable defines a natural ordering for objects using the compareTo() method.

82. What is Comparator?

Answer: Comparator defines custom ordering separately from the class being compared.

83. Comparable vs Comparator?

Answer: Comparable defines natural ordering inside the class, while Comparator allows separate custom sorting logic.

84. What are generics?

Answer: Generics allow classes, interfaces and methods to work with specified types while providing compile-time type safety.

85. Why are generics useful?

Answer: Generics reduce type-casting and help detect type errors during compilation.

Exception Handling — Questions 86–95

86. What is an exception?

Answer: An exception is an event that disrupts the normal flow of program execution.

87. What is exception handling?

Answer: Exception handling provides mechanisms to detect and handle exceptional conditions.

88. What is try?

Answer: The try block contains code that may throw an exception.

89. What is catch?

Answer: The catch block handles an exception thrown from a corresponding try block.

90. What is finally?

Answer: The finally block is commonly used for cleanup code and generally executes after try/catch processing.

91. Difference between checked and unchecked exceptions?

Answer: Checked exceptions are checked by the compiler. Unchecked exceptions are RuntimeException subclasses and are not required to be declared or caught.

92. What is throw?

Answer: throw is used to explicitly throw an exception.

93. What is throws?

Answer: throws declares exceptions that a method may pass to its caller.

94. Can we have multiple catch blocks?

Answer: Yes. A try block can be followed by multiple catch blocks for different exception types.

95. What is a custom exception?

Answer: A custom exception is a user-defined exception class created for application-specific error conditions.

Multithreading — Questions 96–105

96. What is a thread?

Answer: A thread is a lightweight unit of execution within a process.

97. What is multithreading?

Answer: Multithreading allows multiple threads to execute concurrently within a program.

98. How can a thread be created?

Answer: Common approaches include extending Thread or implementing Runnable.

99. What is Runnable?

Answer: Runnable is a functional interface representing an operation that can be executed by a thread.

100. What is thread lifecycle?

Answer: A thread moves through states such as new, runnable, blocked/waiting, timed waiting and terminated.

101. What is sleep()?

Answer: sleep() pauses the currently executing thread for a specified period.

102. What is join()?

Answer: join() allows one thread to wait for another thread to complete.

103. What is synchronization?

Answer: Synchronization controls concurrent access to shared resources to help prevent race conditions.

104. What is a race condition?

Answer: A race condition occurs when program behavior depends on the timing of concurrent operations on shared data.

105. What is deadlock?

Answer: Deadlock occurs when threads wait indefinitely for resources held by each other.

Java 8+ Features — Questions 106–120

106. What is a lambda expression?

Answer: A lambda expression provides a concise way to represent behavior, especially for functional interfaces.

107. What is a functional interface?

Answer: A functional interface has exactly one abstract method.

108. What is Stream API?

Answer: Stream API provides a declarative way to process collections and other data sources.

109. What is filter() in streams?

Answer: filter() selects elements that satisfy a given condition.

110. What is map() in streams?

Answer: map() transforms each stream element into another value.

111. What is collect()?

Answer: collect() is a terminal stream operation used to gather processed elements into a result such as a List.

112. What is Optional?

Answer: Optional is a container type designed to represent a value that may or may not be present.

113. What is a method reference?

Answer: A method reference is a shorter syntax for referring to an existing method or constructor.

114. What is a default method in an interface?

Answer: A default method is an interface method that contains an implementation.

115. What is an interface static method?

Answer: A static method belongs to the interface itself and can be called using the interface name.

116. What is forEach()?

Answer: forEach() performs an action for each element in a collection or stream.

117. What is Predicate?

Answer: Predicate is a functional interface that represents a boolean-valued condition.

118. What is Consumer?

Answer: Consumer is a functional interface that accepts a value and returns no result.

119. What is Function?

Answer: Function is a functional interface that accepts one argument and produces a result.

120. What is Supplier?

Answer: Supplier is a functional interface that provides a result without taking an input argument.

JDBC & Database — Questions 121–135

121. What is JDBC?

Answer: JDBC stands for Java Database Connectivity. It provides an API for Java applications to interact with databases.

122. What is a JDBC driver?

Answer: A JDBC driver enables Java applications to communicate with a particular database system.

123. What is Connection?

Answer: Connection represents a session between a Java application and a database.

124. What is Statement?

Answer: Statement is used to execute SQL statements against a database.

125. What is PreparedStatement?

Answer: PreparedStatement represents a precompiled SQL statement and supports parameterized queries.

126. Why is PreparedStatement preferred?

Answer: It supports parameterized queries, improves reuse and helps reduce SQL injection risks.

127. What is ResultSet?

Answer: ResultSet represents data returned by a query and allows the application to iterate through rows.

128. What is executeQuery()?

Answer: executeQuery() is commonly used for SQL statements that return a ResultSet, such as SELECT.

129. What is executeUpdate()?

Answer: executeUpdate() is commonly used for INSERT, UPDATE and DELETE statements and returns the affected row count.

130. What is database connection pooling?

Answer: Connection pooling reuses database connections instead of creating a new connection for every operation.

131. What is SQL injection?

Answer: SQL injection is an attack where malicious SQL input changes the intended database query.

132. How can SQL injection be prevented?

Answer: Parameterized queries using PreparedStatement are a common defense.

133. What is a transaction?

Answer: A transaction is a group of database operations treated as a logical unit of work.

134. What is commit?

Answer: Commit permanently saves the changes made during a database transaction.

135. What is rollback?

Answer: Rollback reverses changes made during a transaction since the relevant transaction boundary.

Advanced Java — Questions 136–145

136. What is reflection in Java?

Answer: Reflection allows a program to inspect and interact with classes, methods, fields and constructors at runtime.

137. What is serialization?

Answer: Serialization converts an object's state into a form that can be stored or transmitted.

138. What is deserialization?

Answer: Deserialization reconstructs an object from its stored serialized representation.

139. What is transient?

Answer: The transient keyword can prevent a field from being included in default Java serialization.

140. What is an immutable class?

Answer: An immutable class is designed so that its observable state cannot be changed after object creation.

141. How can you create an immutable class?

Answer: Common practices include making the class final, fields private and final, initializing through constructors, and avoiding methods that modify state.

142. What is an enum?

Answer: An enum is a special type used to represent a fixed set of named constants.

143. What is an annotation?

Answer: An annotation provides metadata about program elements such as classes, methods and fields.

144. What is dependency injection?

Answer: Dependency injection provides an object's required dependencies from outside rather than making the object create them itself.

145. What is an API?

Answer: API stands for Application Programming Interface. It defines ways for software components to communicate or use provided functionality.

HR & Project Interview Questions — 146–155

146. Tell me about yourself.

Model Answer: Give a short introduction covering your education, technical skills, projects, strengths and career goal.

Interview Tip: Keep your introduction clear and around 1–2 minutes.
147. Why did you choose Java?

Model Answer: Java has strong object-oriented concepts, a large ecosystem, good industry usage and supports development of reliable applications.

148. What Java project have you worked on?

Model Answer: Explain your project name, objective, technologies, your role, important features and what you learned.

149. What was your role in the project?

Model Answer: Clearly describe the parts you personally designed, developed, tested or documented.

150. What challenges did you face in your project?

Model Answer: Explain one real technical problem, the steps you took to solve it and what you learned from the experience.

151. How do you debug a Java program?

Model Answer: Reproduce the issue, inspect the error message and stack trace, use debugging tools or logs, isolate the cause and test the fix.

152. What are your strengths?

Model Answer: Mention strengths relevant to the role, such as willingness to learn, problem solving, consistency, teamwork and technical curiosity.

153. What is your weakness?

Model Answer: Choose a genuine but manageable weakness and explain the practical steps you are taking to improve it.

154. Where do you see yourself in five years?

Model Answer: Describe a realistic career direction focused on technical growth, responsibility and continuous learning.

155. Why should we hire you?

Model Answer: Connect your relevant technical skills, project experience, learning attitude and ability to contribute to the role.

Interview Tip: Give specific evidence instead of only using general statements.
