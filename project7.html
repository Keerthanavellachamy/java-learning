Project Overview

The Expense Tracker is a Java application that allows users to record, manage and analyse their daily expenses. Users can categorise expenses and view monthly spending summaries to understand their financial activities.

Project Goal: Create an expense management system while applying Java Streams, JDBC, Collections and object-oriented programming.

Project Features

  • Add New Expense
  • Update Expense
  • Delete Expense
  • View All Expenses
  • Expense Categories
  • Monthly Expense Summary
  • Search Expenses
  • Total Spending Calculation

  • Classes and Objects

Technologies Used

The Expense Tracker combines Java programming with database connectivity and stream-based data processing.

Java OOP Collections ArrayList Streams JDBC SQL Exception Handling

Expense Tracker Modules

👤 User Module Users can manage their expense records.
💵 Expense Module Add, update and delete individual expense records.
🏷 Category Module Organise expenses into different categories.
📅 Date Module Store and filter expenses based on dates.
📊 Report Module Generate monthly spending summaries.
💰 Budget Module Compare spending against a planned budget.

Expense Categories
