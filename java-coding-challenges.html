1. Reverse a String

Write a Java program to reverse a given string without using StringBuilder.

Input: Hello Output: olleH
Solution:
String str = "Hello"; String reverse = ""; for(int i = str.length() - 1; i >= 0; i--) { reverse += str.charAt(i); } System.out.println(reverse);

2. Check Whether a Number is Prime

Write a Java program to check whether a given number is prime.

Input: 7 Output: Prime
Solution:
int n = 7; boolean prime = true; if(n <= 1) { prime = false; } for(int i = 2; i <= n / 2; i++) { if(n % i == 0) { prime = false; break; } } System.out.println(prime ? "Prime" : "Not Prime");

3. Find the Second Largest Element

Write a Java program to find the second largest number in an integer array.

Input: 10, 20, 5, 30, 15 Output: 20
Solution:
int[] arr = {10, 20, 5, 30, 15}; int largest = Integer.MIN_VALUE; int second = Integer.MIN_VALUE; for(int n : arr) { if(n > largest) { second = largest; largest = n; } else if(n > second && n != largest) { second = n; } } System.out.println(second);

4. Check Palindrome String

Write a Java program to check whether a string is a palindrome.

Input: madam Output: Palindrome
Solution:
String str = "madam"; String reverse = ""; for(int i = str.length() - 1; i >= 0; i--) { reverse += str.charAt(i); } if(str.equals(reverse)) { System.out.println("Palindrome"); } else { System.out.println("Not Palindrome"); }

5. Find Factorial of a Number

Write a Java program to find the factorial of a number.

Input: 5 Output: 120
Solution:
int n = 5; int factorial = 1; for(int i = 1; i <= n; i++) { factorial *= i; } System.out.println(factorial);

6. Find Largest Element in an Array

Write a Java program to find the largest element in an array.

Input: 5, 12, 8, 20, 3 Output: 20
Solution:
int[] arr = {5, 12, 8, 20, 3}; int largest = arr[0]; for(int n : arr) { if(n > largest) { largest = n; } } System.out.println(largest);

7. Count Vowels in a String

Write a Java program to count the number of vowels in a given string.

Input: Java Programming Output: 5
Solution:
String str = "Java Programming"; int count = 0; for(char ch : str.toLowerCase().toCharArray()) { if(ch == 'a' || ch == 'e' || ch == 'i' || ch == 'o' || ch == 'u') { count++; } } System.out.println(count);
