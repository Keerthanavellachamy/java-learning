What is an Enum?

An enum, short for enumeration, is a special Java type used to represent a fixed collection of constants.

Use an enum when a variable should have only a predefined set of possible values.

Real-World Examples

  • Days of the week
  • Months of the year
  • Order status
  • Traffic light colors
  • User roles
  • Payment status

Creating an Enum

Use the enum keyword to create an enumeration.

Day.java 
enum Day {

    MONDAY,
    TUESDAY,
    WEDNESDAY,
    THURSDAY,
    FRIDAY,
    SATURDAY,
    SUNDAY
}

Each value inside the enum is called an enum constant.

Using an Enum

You can create a variable whose type is the enum.

Main.java 
Day today = Day.MONDAY;

System.out.println(today);
Output:
MONDAY

Enum Values

Enum constants are accessed using the enum type name followed by a dot.

Example.java 
Day day1 = Day.MONDAY;

Day day2 = Day.FRIDAY;

System.out.println(day1);
System.out.println(day2);
Output:
MONDAY
FRIDAY

Enum with if Statement

Enums can be compared using normal control statements.

Main.java 
Day day = Day.SUNDAY;

if (day == Day.SUNDAY) {

    System.out.println(
        "It's a holiday!"
    );
}
Output:
It's a holiday!

Enum with switch

The switch statement works especially well with enum values.

Main.java 
Day day = Day.MONDAY;

switch (day) {

    case MONDAY:
        System.out.println(
            "Start of the week"
        );
        break;

    case FRIDAY:
        System.out.println(
            "Almost weekend"
        );
        break;

    case SATURDAY:
    case SUNDAY:
        System.out.println(
            "Weekend"
        );
        break;

    default:
        System.out.println(
            "Working day"
        );
}
Output:
Start of the week

values() Method

The values() method returns all constants defined inside an enum.

Example.java 
for (Day day : Day.values()) {

    System.out.println(day);
}
Output:
MONDAY
TUESDAY
WEDNESDAY
THURSDAY
FRIDAY
SATURDAY
SUNDAY

valueOf() Method

The valueOf() method converts a matching string into an enum constant.

Example.java 
Day day =
    Day.valueOf("FRIDAY");

System.out.println(day);
Output:
FRIDAY
The string must match the enum constant exactly, including uppercase and lowercase letters.

ordinal() Method

The ordinal() method returns the position of an enum constant.

Example.java 
Day day = Day.WEDNESDAY;

System.out.println(day.ordinal());
Output:
2
Enum positions start from 0. MONDAY is 0, TUESDAY is 1, and WEDNESDAY is 2.

Enums Can Have Methods

Enums are much more powerful than simple constants. They can contain fields, constructors, and methods.

Level.java 
enum Level {

    LOW,
    MEDIUM,
    HIGH;

    void display() {

        System.out.println(
            "Level: " + this
        );
    }
}

Level.HIGH.display();
Output:
Level: HIGH

Enums with Fields

Each enum constant can have its own associated value.

Status.java 
enum Status {

    SUCCESS(200),
    NOT_FOUND(404),
    SERVER_ERROR(500);

    private int code;

    Status(int code) {

        this.code = code;
    }

    int getCode() {

        return code;
    }
}

System.out.println(
    Status.SUCCESS.getCode()
);
Output:
200

Enum Constructors

An enum can have a constructor for initializing its fields.

Enum constructors are implicitly private. You cannot create enum objects using the new keyword.

Enums and OOP

Enums are useful in object-oriented programming because they provide a type-safe way to represent fixed choices.

  • Enums can contain fields.
  • Enums can contain methods.
  • Enums can have constructors.
  • Enums can implement interfaces.

Real-World Example: Order Status

Order.java 
enum OrderStatus {

    PLACED,
    CONFIRMED,
    SHIPPED,
    DELIVERED,
    CANCELLED
}

OrderStatus status =
    OrderStatus.SHIPPED;

System.out.println(
    "Order status: " + status
);
Output:
Order status: SHIPPED

Enum vs Integer Constants

Feature Enum Integer Constants
Type Safety Strong type safety Less type-safe
Readable Very readable Can be less readable
Methods Can contain methods Cannot contain methods
Fields Can contain fields Separate variables required
Best Use Fixed set of choices Simple numeric values

Advantages of Enums

  • Easy to read.
  • Provides type safety.
  • Prevents invalid predefined values.
  • Can contain methods and fields.
  • Works well with switch statements.

Important Limitations

  • Enum constants are fixed after declaration.
  • You cannot create enum objects using new.
  • Adding too many fields or methods can make an enum complex.
  • ordinal() should not normally be used as a permanent database ID.

Lesson Summary

Enums are special Java types used to represent a fixed set of constants. They make programs easier to understand and provide type-safe values.


Enums can also contain fields, constructors, and methods, making them a useful part of object-oriented Java programming.
