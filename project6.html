Project Overview

The Online Quiz Application is a Java application that allows users to participate in quizzes and answer multiple-choice questions. The system calculates scores automatically and displays the final result after the quiz.

Project Goal: Create an interactive quiz system while applying Java Collections, Swing, event handling and object-oriented programming concepts.

Project Features

  • User Registration
  • Quiz Categories
  • Multiple Choice Questions
  • Timed Quiz
  • Automatic Score Calculation
  • Result Display
  • Leaderboard
  • Question Management

Quiz Modules

👤 User Module Users can enter their name and start a quiz.
📚 Category Module Users can select different quiz categories.
❓ Question Module Displays questions with multiple answer choices.
⏱ Timer Module Provides a limited amount of time for completing the quiz.
🏆 Score Module Calculates the user's score automatically.
📊 Leaderboard Displays top quiz scores achieved by users.

Scoring Rules
