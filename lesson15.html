What is Abstraction?

Abstraction means hiding complex implementation details and showing only the essential features of an object.

Simple idea:

Hide how something works → Show what it does

For example, when you use an ATM, you select Withdraw Money. You do not need to know the internal banking operations that happen behind the screen.

Real-World Example

Consider a car. You use the steering wheel, accelerator, brake, and gear system.

You do not need to know every internal engine operation to drive the car.

What you see: Driving controls

What is hidden: Internal engine implementation

Why Use Abstraction?

  • Reduces complexity.
  • Hides unnecessary implementation details.
  • Improves code organization.
  • Provides a clear interface to users.
  • Makes software easier to maintain.

Abstraction in Java

Java provides two major ways to achieve abstraction:

1. Abstract Classes
Used when classes share common state or behavior.

2. Interfaces
Used to define a contract that implementing classes must follow.

Abstract Class

An abstract class is a class declared using the abstract keyword.

It can contain both abstract methods and normal methods. 

abstract class Animal {

    abstract void sound();

    void eat() {
        System.out.println("Animal eats");
    }
}

Abstract Method

An abstract method is a method declared without a body. 

abstract void sound();
Important: The child class must provide the implementation of an abstract method.

Child Implementation

A concrete child class extends the abstract class and implements its abstract methods. 

class Dog extends Animal {

    @Override
    void sound() {
        System.out.println("Dog barks");
    }
}

Complete Abstraction Example

abstract class Animal {

    abstract void sound();

    void eat() {
        System.out.println("Animal eats");
    }
}

class Dog extends Animal {

    @Override
    void sound() {
        System.out.println("Dog barks");
    }
}

public class Main {

    public static void main(String[] args) {

        Dog dog = new Dog();

        dog.sound();
        dog.eat();
    }
}
Dog barks Animal eats

Abstract Class Rules

  • An abstract class uses the abstract keyword.
  • It can contain abstract methods.
  • It can contain normal methods.
  • It can contain variables.
  • It can have constructors.
  • An abstract class cannot be instantiated directly.

Cannot Create Object Directly

You cannot create an object directly from an abstract class. 

abstract class Animal {
}

// Not allowed
Animal animal =
    new Animal();
Why? An abstract class may contain methods that do not have an implementation.

Abstraction vs Encapsulation

Feature Abstraction Encapsulation
Main purpose Hide implementation details Protect and control data
Focus What an object does How data is accessed
Common tools Abstract classes, Interfaces Private fields, Getters, Setters
Example ATM interface Private bank balance

Partial Abstraction

An abstract class can provide both abstract methods and implemented methods.

Example:

Abstract method → no implementation
Normal method → implementation provided

Full Abstraction

Interfaces are commonly used when you want to define a contract without providing implementation details for the required behavior.

Note: Interfaces will be covered in detail in later lessons.

Real-World Example: Payment

A payment system can define what a payment method should do without forcing users to know the internal payment processing logic. 

abstract class Payment {

    abstract void pay();

    void receipt() {
        System.out.println("Receipt generated");
    }
}

class UPIPayment extends Payment {

    @Override
    void pay() {
        System.out.println("Payment made using UPI");
    }
}

public class Main {

    public static void main(String[] args) {

        UPIPayment payment =
            new UPIPayment();

        payment.pay();
        payment.receipt();
    }
}
Payment made using UPI Receipt generated

Benefits of Abstraction

  • Reduces complexity.
  • Improves security by hiding implementation details.
  • Provides cleaner code.
  • Makes maintenance easier.
  • Improves flexibility.

Important Points

  • Abstraction focuses on essential behavior.
  • Abstract classes use the abstract keyword.
  • Abstract methods do not have a method body.
  • Child classes implement abstract methods.
  • Abstract classes cannot be instantiated directly.
  • Interfaces are another major way to achieve abstraction.
