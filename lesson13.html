What is Method Overloading?

Method overloading means defining multiple methods in the same class with the same method name but different parameters.

Simple idea:

Same method name + Different parameters = Method Overloading

Method overloading is an example of compile-time polymorphism.

Basic Example

The following class contains three add() methods. 

class Calculator {

    int add(int a, int b) {
        return a + b;
    }

    int add(int a, int b, int c) {
        return a + b + c;
    }

    double add(double a, double b) {
        return a + b;
    }
}

All three methods are named add(), but their parameter lists are different.

Different Number of Parameters

Methods can be overloaded by changing the number of parameters. 

void display() {
    System.out.println("No arguments");
}

void display(int number) {
    System.out.println(number);
}

void display(int a, int b) {
    System.out.println(a + b);
}

Different Parameter Types

Methods can also be overloaded by changing the data types of their parameters. 

void show(int number) {
    System.out.println("Integer");
}

void show(String text) {
    System.out.println("String");
}

void show(double value) {
    System.out.println("Double");
}

Changing Parameter Order

Methods can also be overloaded by changing the order of parameters when their types are different. 

void display(int number, String text) {
    System.out.println("Integer first");
}

void display(String text, int number) {
    System.out.println("String first");
}
Important: The parameter order is part of the method signature.

Complete Program

class Calculator {

    int add(int a, int b) {
        return a + b;
    }

    int add(int a, int b, int c) {
        return a + b + c;
    }

    double add(double a, double b) {
        return a + b;
    }
}

public class Main {

    public static void main(String[] args) {

        Calculator calc = new Calculator();

        System.out.println(calc.add(10, 20));

        System.out.println(calc.add(10, 20, 30));

        System.out.println(calc.add(10.5, 20.5));
    }
}

Method Signature

A method signature consists of the method name and its parameter list.

Example:

add(int, int)
add(int, int, int)
add(double, double)

Can Return Type Alone Overload?

No. Changing only the return type is not enough to overload a method. 

// Invalid overloading

int calculate(int a) {
    return a;
}

double calculate(int a) {
    return a;
}
Remember: The parameter list must be different.

Constructor Overloading

Constructors can also be overloaded using different parameter lists. 

class Student {

    Student() {
        System.out.println("Default constructor");
    }

    Student(String name) {
        System.out.println("Name: " + name);
    }

    Student(String name, int age) {
        System.out.println("Name: " + name);
        System.out.println("Age: " + age);
    }
}

Real-World Example

A payment system may allow users to make payments using different amounts and payment details. 

class Payment {

    void pay(double amount) {
        System.out.println("Paid: " + amount);
    }

    void pay(double amount, String cardNumber) {
        System.out.println("Paid by card: " + amount);
    }

    void pay(double amount, String upiId, boolean verified) {
        System.out.println("Paid by UPI: " + amount);
    }
}
Benefit: The same pay() method name can support different payment situations.

Rules of Overloading

  • Methods must have the same name.
  • Parameters must be different.
  • Parameter count can be different.
  • Parameter types can be different.
  • Parameter order can be different.
  • Return type alone cannot create overloading.

Advantages

  • Improves code readability.
  • Uses meaningful and consistent method names.
  • Supports compile-time polymorphism.
  • Reduces unnecessary method names.
  • Makes APIs easier to use.

Overloading vs Overriding

Parameters Must be different Normally same
Inheritance required? No Yes
