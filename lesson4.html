What are Conditional Statements?

Conditional statements allow a Java program to make decisions. The program checks a condition and executes specific code depending on whether the condition is true or false.

💡 Simple Example

If a student's mark is greater than or equal to 50, the student passes. Otherwise, the student fails.

if Statement

The if statement executes a block of code only when the given condition is true.

IfExample.java 
int age = 20;

if (age >= 18) {

    System.out.println("You are eligible.");

}
OUTPUT

You are eligible.

if-else Statement

The if-else statement is used when there are two possible outcomes.

IfElseExample.java 
int mark = 75;

if (mark >= 50) {

    System.out.println("Pass");

} else {

    System.out.println("Fail");

}
OUTPUT

Pass

else-if Statement

The else-if statement is useful when we need to check multiple conditions.

Grade.java 
int mark = 85;

if (mark >= 90) {

    System.out.println("Grade A+");

} else if (mark >= 80) {

    System.out.println("Grade A");

} else if (mark >= 70) {

    System.out.println("Grade B");

} else {

    System.out.println("Grade C");

}
OUTPUT

Grade A

Nested if Statement

A nested if means placing one if statement inside another if statement.

NestedIf.java 
int age = 20;
boolean idCard = true;

if (age >= 18) {

    if (idCard) {

        System.out.println("Entry allowed");

    }

}
OUTPUT

Entry allowed

switch Statement

The switch statement is used when we want to select one option from several possible values.

Day.java 
int day = 2;

switch (day) {

    case 1:
        System.out.println("Monday");
        break;

    case 2:
        System.out.println("Tuesday");
        break;

    case 3:
        System.out.println("Wednesday");
        break;

    default:
        System.out.println("Invalid day");

}
OUTPUT

Tuesday

💡 Remember

The break statement stops the switch from continuing to the next case.

Common Conditions

Condition Meaning
age > 18 Age is greater than 18
age >= 18 Age is 18 or above
mark < 50 Mark is below 50
a == b Both values are equal
a != b Both values are different
