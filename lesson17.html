What is an Interface?

An interface in Java is a blueprint that defines a contract that implementing classes must follow.

Simple idea:

Interface = What a class must do
Class = How the class does it

Interfaces are one of the important tools used to achieve abstraction and loose coupling in Java.

Basic Interface Syntax

interface Animal {

    void sound();
}

class Dog implements Animal {

    @Override
    public void sound() {
        System.out.println("Dog barks");
    }
}

implements Keyword

A class uses the implements keyword to implement an interface. 

interface Vehicle {
    void start();
}

class Car implements Vehicle {

    public void start() {
        System.out.println("Car starts");
    }
}

Interface Methods

Traditionally, interface methods without a body represent behavior that implementing classes must provide. 

interface Animal {

    void eat();
    void sleep();
}
Important: The implementing class must provide implementations for the required abstract methods.

Complete Interface Example

interface Animal {

    void sound();
}

class Dog implements Animal {

    @Override
    public void sound() {
        System.out.println("Dog barks");
    }
}

public class Main {

    public static void main(String[] args) {

        Dog dog = new Dog();

        dog.sound();
    }
}
Dog barks

Interface Reference

An interface reference can refer to an object of a class that implements that interface. 

Animal animal =
    new Dog();

animal.sound();
Benefit: This supports flexible and loosely coupled code.

Multiple Implementations

Multiple classes can implement the same interface, with each class providing its own behavior. 

interface Animal {
    void sound();
}

class Dog implements Animal {

    public void sound() {
        System.out.println("Dog barks");
    }
}

class Cat implements Animal {

    public void sound() {
        System.out.println("Cat meows");
    }
}

Why public is Used?

Interface methods are public by contract. Therefore, when a class implements an interface method, the method cannot reduce its visibility. 

interface Vehicle {

    void start();
}

class Car implements Vehicle {

    public void start() {
        System.out.println("Car starts");
    }
}
Remember: Use public when implementing interface methods.

Variables in Interfaces

Variables declared in an interface are constants. They are implicitly public static final. 

interface Constants {

    int MAX = 100;
}

Using Interface Constants

interface Constants {

    int MAX = 100;
}

public class Main {

    public static void main(String[] args) {

        System.out.println(Constants.MAX);
    }
}
100

Interface and Abstraction

Interfaces are widely used for abstraction because they allow a class to depend on a contract rather than on a specific implementation.

Example: A payment system can define a pay() method. UPI, card, and wallet classes can each implement the method differently.

Real-World Example: Payment

interface Payment {

    void pay();
}

class UPI implements Payment {

    public void pay() {
        System.out.println("Payment through UPI");
    }
}

class Card implements Payment {

    public void pay() {
        System.out.println("Payment through Card");
    }
}

public class Main {

    public static void main(String[] args) {

        Payment payment =
            new UPI();

        payment.pay();
    }
}
Payment through UPI

Benefits of Interfaces

  • Provides abstraction.
  • Supports loose coupling.
  • Allows multiple interfaces to be implemented.
  • Improves flexibility.
  • Encourages clean software design.
  • Makes code easier to extend.

Important Rules

  • Use the interface keyword.
  • Classes use implements.
  • Interface methods are public by contract.
  • Interface fields are constants.
  • A class must implement required abstract methods.
  • An interface cannot be instantiated directly.
