Learn how one reference can represent different types of objects and how the same method call can produce different behavior.

What is Polymorphism?

Polymorphism means "many forms". It allows the same method, object reference, or interface to behave differently depending on the actual object.

Simple idea:

One name → Many behaviors

In Java, polymorphism is mainly achieved through:

  • Method Overloading
  • Method Overriding

Real-World Example

Think about the word draw(). A circle, rectangle, and triangle can all have a draw() method, but each shape draws itself differently.

Same action: draw()
Different behavior: Circle, Rectangle, Triangle

Types of Polymorphism

Type Achieved By
Compile-Time Method Overloading
Run-Time Method Overriding

Compile-Time Polymorphism

Compile-time polymorphism occurs when Java determines which overloaded method should be called during compilation.

It is achieved using method overloading. 

class Calculator {

    int add(int a, int b) {
        return a + b;
    }

    int add(int a, int b, int c) {
        return a + b + c;
    }
}

public class Main {

    public static void main(String[] args) {

        Calculator calc = new Calculator();

        System.out.println(calc.add(10, 20));

        System.out.println(calc.add(10, 20, 30));
    }
}
30 60

Run-Time Polymorphism

Run-time polymorphism occurs when a parent class reference refers to a child class object and the overridden method is selected at runtime. 

class Animal {

    void sound() {
        System.out.println("Animal sound");
    }
}

class Dog extends Animal {

    @Override
    void sound() {
        System.out.println("Dog barks");
    }
}

public class Main {

    public static void main(String[] args) {

        Animal animal = new Dog();

        animal.sound();
    }
}
Dog barks
Important: Although the reference type is Animal, the actual object is Dog. Therefore, the overridden Dog method runs.

Parent Reference

A parent class reference can point to an object of its child class. 

Animal animal;

animal = new Dog();

animal.sound();
Reference Type: Animal
Object Type: Dog

Many Forms

A parent reference can point to different child objects. Each child can provide its own implementation of the same method. 

Animal a1 = new Dog();
Animal a2 = new Cat();

a1.sound();
a2.sound();

Complete Polymorphism Example

class Animal {

    void sound() {
        System.out.println("Animal makes a sound");
    }
}

class Dog extends Animal {

    @Override
    void sound() {
        System.out.println("Dog barks");
    }
}

class Cat extends Animal {

    @Override
    void sound() {
        System.out.println("Cat meows");
    }
}

public class Main {

    public static void main(String[] args) {

        Animal animal;

        animal = new Dog();
        animal.sound();

        animal = new Cat();
        animal.sound();
    }
}
Dog barks Cat meows

Advantages

  • Provides flexibility in program design.
  • Reduces duplicate code.
  • Makes programs easier to extend.
  • Supports loose coupling.
  • Makes object-oriented programs more reusable.

Important Points

  • Polymorphism means many forms.
  • Overloading gives compile-time polymorphism.
  • Overriding gives run-time polymorphism.
  • A parent reference can refer to a child object.
  • Overridden methods are selected at runtime.
  • Polymorphism is one of the four major OOP concepts.

Compile-Time vs Run-Time Polymorphism

Feature Compile-Time Run-Time
Also called Static Polymorphism Dynamic Polymorphism
Achieved using Method Overloading Method Overriding

Lesson Summary

Polymorphism allows Java objects to take many forms. It makes object-oriented programs flexible and reusable.

  • Compile-time polymorphism → Method Overloading
  • Run-time polymorphism → Method Overriding
  • Parent reference → Child object
  • Same method call → Different behavior
