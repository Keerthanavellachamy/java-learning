Why Default and Static Methods?

Older Java interfaces mainly contained abstract methods that implementing classes had to provide.

Modern Java allows interfaces to contain default methods and static methods with method bodies.

Remember:

Abstract method → no body
Default method → has a body and can be inherited
Static method → belongs to the interface itself

What is a Default Method?

A default method is a method inside an interface that contains an implementation.

It is declared using the default keyword. 

interface Animal {

    void sound();

    default void sleep() {
        System.out.println("Animal is sleeping");
    }
}

Using a Default Method

interface Animal {

    void sound();

    default void sleep() {
        System.out.println("Animal is sleeping");
    }
}

class Dog
        implements Animal {

    public void sound() {
        System.out.println("Dog barks");
    }
}

public class Main {

    public static void main(String[] args) {

        Dog dog = new Dog();

        dog.sound();
        dog.sleep();
    }
}
Dog barks Animal is sleeping

Why Use Default Methods?

Default methods allow developers to add new behavior to an existing interface without forcing every implementing class to immediately provide an implementation.

  • Provides reusable behavior.
  • Helps maintain backward compatibility.
  • Allows interfaces to evolve.
  • Reduces repeated code.

Overriding a Default Method

A class can override a default method if it needs different behavior. 

interface Animal {

    default void sound() {
        System.out.println("Animal makes a sound");
    }
}

class Dog
        implements Animal {

    @Override
    public void sound() {
        System.out.println("Dog barks");
    }
}
Result: The class-specific implementation takes priority over the inherited default implementation.

What is a Static Interface Method?

A static method in an interface belongs to the interface itself. It is not inherited by implementing classes.

Static interface methods are called using the interface name. 

interface Calculator {

    static int square(int n) {
        return n * n;
    }
}

Calling Static Method

interface Calculator {

    static int square(int n) {
        return n * n;
    }
}

public class Main {

    public static void main(String[] args) {

        int result =
            Calculator.square(5);

        System.out.println(result);
    }
}

Static Methods Are Not Object Methods

A static interface method should be called using the interface name rather than an implementing object. 

Calculator.square(5);
Remember: Static interface methods belong to the interface.

Default and Static Methods Together

interface Vehicle {

    default void start() {
        System.out.println("Vehicle started");
    }

    static void info() {
        System.out.println("Vehicles are used for transportation");
    }
}

class Car
        implements Vehicle {
}

public class Main {

    public static void main(String[] args) {

        Car car = new Car();

        car.start();

        Vehicle.info();
    }
}
Vehicle started Vehicles are used for transportation

Default Methods with Multiple Interfaces

When two interfaces provide default methods with the same signature, the implementing class must resolve the conflict. 

interface A {

    default void show() {
        System.out.println("A");
    }
}

interface B {

    default void show() {
        System.out.println("B");
    }
}

class C
        implements A, B {

    @Override
    public void show() {
        System.out.println("C");
    }
}
Why? Java requires the class to resolve the ambiguity instead of automatically choosing one interface.

Calling a Specific Default Method

If two interfaces contain the same default method, the implementing class can explicitly call a particular interface's default method using InterfaceName.super.method(). 

interface A {

    default void show() {
        System.out.println("A show");
    }
}

interface B {

    default void show() {
        System.out.println("B show");
    }
}

class C
        implements A, B {

    public void show() {

        A.super.show();
        B.super.show();

        System.out.println("C show");
    }
}
A show B show C show

Important Points

  • Default methods have a method body.
  • Static methods belong to the interface.
  • Default methods can be overridden.
  • Static interface methods cannot be overridden.
  • Static methods are called using the interface name.
  • Default method conflicts must be resolved.

Common Use Cases

  • Adding new functionality to existing interfaces.
  • Providing reusable default behavior.
  • Creating utility methods inside interfaces.
  • Maintaining backward compatibility.
  • Reducing duplicate implementation code.

Lesson Summary

Modern Java interfaces can contain default and static methods in addition to abstract methods.

  • Default methods contain an implementation.
  • Default methods can be inherited and overridden.
  • Static methods belong directly to the interface.
  • Static methods are called using the interface name.
  • Static methods cannot be overridden.
  • Default method conflicts must be resolved by the implementing class.
