What is User Input?

User input means information entered by a person while a program is running.

💡 Example:

A program can ask the user to enter their name, age, marks or phone number.

Scanner Class

Java provides the Scanner class to read input from the keyboard.

ScannerExample.java 
import java.util.Scanner;

class Main {

    public static void main(String[] args) {

        Scanner input = new Scanner(System.in);

    }

}
Remember:

We need to import java.util.Scanner before using the Scanner class.

Reading String Input

The nextLine() method reads a complete line of text.

StringInput.java 
import java.util.Scanner;

class Main {

    public static void main(String[] args) {

        Scanner input = new Scanner(System.in);

        System.out.println("Enter your name:");

        String name = input.nextLine();

        System.out.println("Hello " + name);

    }

}
SAMPLE OUTPUT

Enter your name:
Keerthana
Hello Keerthana

Reading Integer Input

Use nextInt() to read an integer value.

IntegerInput.java 
import java.util.Scanner;

class Main {

    public static void main(String[] args) {

        Scanner input = new Scanner(System.in);

        System.out.println("Enter your age:");

        int age = input.nextInt();

        System.out.println("Your age is " + age);

    }

}
SAMPLE OUTPUT

Enter your age:
20
Your age is 20

Reading Decimal Input

Use nextDouble() to read a decimal number.

}

8.15
Your CGPA is 8.15

Scanner Input Methods

Method Input Type Example
nextLine() String / complete line input.nextLine()
next() Single word input.next()
nextInt() Integer input.nextInt()
nextDouble() Decimal number input.nextDouble()
nextFloat() Float number input.nextFloat()
nextLong() Long integer input.nextLong()
nextBoolean() Boolean input.nextBoolean()

Taking Multiple Inputs

We can take different values from the user in the same program.

StudentInput.java 
import java.util.Scanner;

class Student {

    public static void main(String[] args) {

        Scanner input = new Scanner(System.in);

        System.out.println("Enter your name:");

        String name = input.nextLine();

        System.out.println("Enter your age:");

        int age = input.nextInt();

        System.out.println("Enter your CGPA:");

        double cgpa = input.nextDouble();

        System.out.println("Name: " + name);

        System.out.println("Age: " + age);

        System.out.println("CGPA: " + cgpa);

    }

}

Practical Example — Addition

Let's create a program that takes two numbers from the user and calculates their sum.

AddNumbers.java 
import java.util.Scanner;

class AddNumbers {

    public static void main(String[] args) {

        Scanner input = new Scanner(System.in);

        System.out.println("Enter first number:");

        int a = input.nextInt();

        System.out.println("Enter second number:");

        int b = input.nextInt();

        int sum = a + b;

        System.out.println("Sum = " + sum);

    }

}
SAMPLE OUTPUT

Enter first number:
10
Enter second number:
20
Sum = 30

Practical Example — Student Marks

We can also use Scanner to calculate the total and average of marks.

Marks.java 
import java.util.Scanner;

class Marks {

    public static void main(String[] args) {

        Scanner input = new Scanner(System.in);

        System.out.println("Enter mark 1:");

        int mark1 = input.nextInt();

        System.out.println("Enter mark 2:");

        int mark2 = input.nextInt();

        System.out.println("Enter mark 3:");

        int mark3 = input.nextInt();

        int total = mark1 + mark2 + mark3;

        double average = total / 3.0;

        System.out.println("Total = " + total);

        System.out.println("Average = " + average);

    }

}
SAMPLE OUTPUT

Enter mark 1:
80
Enter mark 2:
90
Enter mark 3:
85
Total = 255
Average = 85.0

Important Note

⚠️ nextInt() and nextLine()

When using nextInt() before nextLine(), you may need an extra input.nextLine() to consume the remaining newline.

InputFix.java 
int age = input.nextInt();

input.nextLine();

String name = input.nextLine();
