What is an Exception?

An exception is an unexpected problem that occurs while a Java program is running.

💡 Example:

Trying to divide a number by zero can cause an exception.

Example Without Exception Handling

Consider the following program.

ErrorExample.java 
class Main {

    public static void main(String[] args) {

        int a = 10;

        int b = 0;

        int result = a / b;

        System.out.println(result);

    }

}
⚠️ ERROR

ArithmeticException: / by zero

try-catch

The try-catch statement allows us to handle an exception without stopping the entire program unexpectedly.

TryCatch.java 
try {

    int result = 10 / 0;

}

catch (ArithmeticException e) {

    System.out.println("Cannot divide by zero");

}
OUTPUT

Cannot divide by zero

💡 Remember:

Code that may cause an exception is placed inside try. The exception is handled inside catch.

Complete try-catch Program

Main.java 
class Main {

    public static void main(String[] args) {

        try {

            int a = 20;

            int b = 0;

            int result = a / b;

            System.out.println(result);

        }

        catch (ArithmeticException e) {

            System.out.println(
                "Division by zero is not allowed"
            );

        }

    }

}
OUTPUT

Division by zero is not allowed

finally Block

The finally block contains code that executes after the try-catch process.

FinallyExample.java 
try {

    System.out.println("Try block");

}

catch (Exception e) {

    System.out.println("Exception occurred");

}

finally {

    System.out.println("Finally block executed");

}
OUTPUT

Try block
Finally block executed

Getting the Exception Message

The getMessage() method can be used to get a message describing an exception.

Message.java 
try {

    int result = 10 / 0;

}

catch (ArithmeticException e) {

    System.out.println(e.getMessage());

}
OUTPUT

/ by zero

Common Java Exceptions

Exception Cause
ArithmeticException Invalid arithmetic operation such as division by zero.
ArrayIndexOutOfBoundsException Trying to access an invalid array index.
NullPointerException Trying to use a null object reference.
NumberFormatException Invalid conversion from String to number.
InputMismatchException Input does not match the expected type.

Array Exception Example

An exception can also occur when we access an array position that does not exist.

ArrayError.java 
class Main {

    public static void main(String[] args) {

        int[] numbers = {10, 20, 30};

        try {

            System.out.println(numbers[5]);

        }

        catch (ArrayIndexOutOfBoundsException e) {

            System.out.println("Invalid array index");

        }

    }

}
OUTPUT

Invalid array index

Multiple catch Blocks

A program can have multiple catch blocks to handle different types of exceptions.

MultipleCatch.java 
try {

    int[] numbers = {10, 20};

    System.out.println(numbers[5]);

}

catch (ArithmeticException e) {

    System.out.println("Arithmetic error");

}

catch (ArrayIndexOutOfBoundsException e) {

    System.out.println("Array index error");

}
OUTPUT

Array index error

Exception Handling Structure

Structure 
try {

    // Code that may cause an exception

}

catch (ExceptionType e) {

    // Code to handle the exception

}

finally {

    // Code that executes afterward

}
