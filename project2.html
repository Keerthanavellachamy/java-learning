Project Overview

The Library Management System is a Java application designed to manage books, members and library transactions. The application allows the librarian to add books, register members, search books and manage book issue and return operations.

Project Goal: Create a practical Java application that manages a library's books, members and borrowing activities.

Project Features

  • Add new books
  • View all books
  • Search books
  • Register members
  • Issue books
  • Return books
  • Track available books
  • Manage library records

Java Concepts

  • Classes and Objects
  • Encapsulation
  • Inheritance
  • Polymorphism
  • ArrayList
  • Exception Handling
  • File Handling

Technologies Used

The project combines the following Java concepts and technologies.

Java OOP Collections ArrayList Interfaces Exception Handling File Handling CRUD

Project Modules

📖 Book Management Add, view, search and manage library books.
👤 Member Management Register and manage library members.
📤 Issue Book Issue available books to registered members.
📥 Return Book Return books and update their availability.
🔍 Search Search books by ID, title or author.
📊 Library Records View current books and borrowing information.
