Java Interview Questions

Practice commonly asked Java interview questions with simple explanations.

1. What is Java?

Java is a high-level, object-oriented programming language designed to be platform independent.

2. What is JVM?

JVM stands for Java Virtual Machine. It executes Java bytecode and allows Java programs to run on different platforms.

3. What is the difference between JDK, JRE and JVM?

JDK is used to develop Java applications. JRE provides the environment required to run Java applications. JVM executes Java bytecode.

4. What is a class in Java?

A class is a blueprint or template used to create objects. It can contain variables, methods and constructors.

5. What is an object?

An object is an instance of a class. It represents an entity that contains state and behavior.

6. What is inheritance?

Inheritance allows one class to acquire properties and methods from another class.

7. What is polymorphism?

Polymorphism means one interface or method can have different behaviors depending on the object or implementation.

8. What is encapsulation?

Encapsulation is the process of combining data and methods inside a class and controlling access to the data.

9. What is abstraction?

Abstraction hides implementation details and shows only the essential features of an object.

10. What is method overloading?

Method overloading occurs when multiple methods have the same name but different parameter lists.

11. What is method overriding?

Method overriding occurs when a child class provides its own implementation of a method inherited from the parent class.

12. What is a constructor?

A constructor is a special method used to initialize objects. It has the same name as the class.

13. What is the difference between == and equals()?

The == operator compares references for objects, while equals() is generally used to compare object contents.

14. What is an interface?

An interface defines a contract that implementing classes must follow. A class can implement one or more interfaces.

15. What is an abstract class?

An abstract class is a class that cannot be directly instantiated and can contain abstract and concrete methods.
