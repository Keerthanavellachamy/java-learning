Multiple Interfaces

Learn how a single Java class can implement multiple interfaces and combine different contracts into one flexible object.

2+ Interfaces

What are Multiple Interfaces?

Java does not allow a class to extend multiple classes. However, a class can implement multiple interfaces.

Simple idea:

One class → Multiple interfaces → Multiple responsibilities

This feature allows Java classes to combine behaviors from different interfaces without using multiple class inheritance.

Basic Syntax

interface Printable {
    void print();
}

interface Scannable {
    void scan();
}

class Printer
        implements Printable, Scannable {

    public void print() {
        System.out.println("Printing document");
    }

    public void scan() {
        System.out.println("Scanning document");
    }
}

Using Commas

Multiple interfaces are separated by commas after the implements keyword. 

class Machine
    implements
    Printable,
    Scannable {

}

Why Use Multiple Interfaces?

  • Combines different behaviors.
  • Supports flexible designs.
  • Encourages loose coupling.
  • Avoids multiple class inheritance.
  • Allows one class to follow multiple contracts.

Complete Example

interface Printable {

    void print();
}

interface Scannable {

    void scan();
}

class Printer
        implements Printable, Scannable {

    @Override
    public void print() {
        System.out.println("Printing document");
    }

    @Override
    public void scan() {
        System.out.println("Scanning document");
    }
}

public class Main {

    public static void main(String[] args) {

        Printer printer =
            new Printer();

        printer.print();
        printer.scan();
    }
}
Printing document Scanning document

Implementing Three Interfaces

A class can implement more than two interfaces. The number of interfaces is not limited to two. 

interface Printable {
    void print();
}

interface Scannable {
    void scan();
}

interface Faxable {
    void fax();
}

class OfficeMachine
        implements Printable,
        Scannable, Faxable {

    public void print() {
        System.out.println("Printing");
    }

    public void scan() {
        System.out.println("Scanning");
    }

    public void fax() {
        System.out.println("Sending fax");
    }
}

Interface References

The same object can be referenced using different interface types. 

Printer printer =
    new Printer();

Printable p = printer;
Scannable s = printer;

p.print();
s.scan();

Flexible Design

Interface references allow code to focus on the behavior it needs instead of depending on a specific implementation class.

Example: A method that only needs printing can accept a Printable reference.

Real-World Example: Smartphone

A smartphone can perform many different roles. We can represent each capability with a separate interface. 

interface Camera {
    void takePhoto();
}

interface MusicPlayer {
    void playMusic();
}

interface Phone {
    void makeCall();
}

class Smartphone
        implements Camera,
        MusicPlayer, Phone {

    public void takePhoto() {
        System.out.println("Photo taken");
    }

    public void playMusic() {
        System.out.println("Music playing");
    }

    public void makeCall() {
        System.out.println("Calling...");
    }
}

Multiple Inheritance Through Interfaces

Java does not support multiple inheritance through classes. 

// Not allowed

class C
    extends A, B {
}

But Java allows a class to implement multiple interfaces. 

class C
    implements A, B {
}

Implement All Required Methods

If a class implements multiple interfaces, it must provide implementations for all required abstract methods unless the class itself is abstract.

Abstract Class + Interfaces

A class can extend one class and implement multiple interfaces at the same time. 

class SmartCar
    extends Vehicle
    implements GPS, Bluetooth {

}

Benefits

  • Supports multiple contracts.
  • Encourages modular design.
  • Improves flexibility.
  • Supports loose coupling.
  • Promotes reusable behavior.
  • Avoids multiple class inheritance.

Important Rules

  • Use commas between interface names.
  • Use implements only once.
  • Implement all required methods.
  • Implemented interface methods must be public.
  • A class can extend one class and implement many interfaces.

Single vs Multiple Interfaces

Feature Single Interface Multiple Interfaces
Number of interfaces One Two or more
Syntax implements A implements A, B
Responsibilities One main contract Multiple contracts
Flexibility Good Higher for multiple capabilities

Lesson Summary

Multiple interfaces allow a Java class to combine different contracts and behaviors. This is one of the main ways Java supports multiple inheritance of type.

  • A class can implement multiple interfaces.
  • Interface names are separated using commas.
  • All required methods must be implemented.
  • A class can extend one class and implement multiple interfaces.
  • Multiple interfaces provide flexible and modular designs.
  • They help avoid the problems of multiple class inheritance.
