Inner Classes

Learn how Java allows one class to be declared inside another class and how inner classes can access members of the outer class.

What is an Inner Class?

An inner class is a class that is declared inside another class. The class containing the inner class is called the outer class.

Inner classes are useful when a helper class belongs closely to another class and does not need to be used independently.

Why Use Inner Classes?

  • Group logically related classes together.
  • Improve code organization.
  • Hide helper implementation details.
  • Allow access to outer class members.
  • Improve encapsulation in suitable situations.

Types of Nested Classes

Java supports different forms of classes declared inside another class.

  • Member Inner Class – non-static class declared inside another class.
  • Static Nested Class – static class declared inside another class.
  • Local Inner Class – class declared inside a method or block.
  • Anonymous Inner Class – class without a name, usually used for one-time implementation.
Technically, a static nested class is a nested class but not an "inner class" in the strict Java terminology. Non-static nested classes are called inner classes.

Member Inner Class

A member inner class is declared directly inside an outer class. It can access the members of the outer class.

Outer.java 
class Outer {
    private int value = 10;

    class Inner {

        void display() {
            System.out.println(value);
        }
    }
}

Creating an Inner Class Object

To create an object of a non-static inner class, first create an object of the outer class.

Main.java 
Outer outer = new Outer();

Outer.Inner inner = outer.new Inner();

inner.display();
Output:
10

Accessing Private Members

An inner class can directly access private members of its outer class.

Example.java 
class Bank {

    private double balance = 5000;

    class Account {

        void showBalance() {
            System.out.println(balance);
        }
    }
}
The inner class can access the private balance variable because it belongs to the same outer class context.

Outer Class Accessing Inner Class

The outer class can create an object of its inner class and call its methods.

Example.java 
class Computer {

    class Processor {

        void start() {
            System.out.println(
                "Processor started"
            );
        }
    }

    void run() {

        Processor p = new Processor();

        p.start();
    }
}

Static Nested Class

A static nested class is declared using the static keyword. It does not require an object of the outer class to be created.

Outer.java 
class Outer {

    static int value = 20;

    static class Nested {

        void display() {
            System.out.println(value);
        }
    }
}

Creating Static Nested Object

A static nested class can be accessed using the outer class name.

Main.java 
Outer.Nested obj =
    new Outer.Nested();

obj.display();
Output:
20

Static Nested Class Limitation

A static nested class can directly access static members of the outer class.

It cannot directly access non-static instance members because those members belong to an object of the outer class.

Remember: Static nested classes do not need an outer class object.

Local Inner Class

A local inner class is declared inside a method, constructor, or block. Its scope is limited to that location.

Example.java 
class Outer {

    void display() {

        class Local {

            void show() {
                System.out.println(
                    "Local inner class"
                );
            }
        }

        Local obj = new Local();

        obj.show();
    }
}
Output:
Local inner class

Anonymous Inner Class

An anonymous inner class is a class without a name. It is commonly used when an implementation is required only once.

Main.java 
interface Greeting {

    void sayHello();
}

public class Main {

    public static void main(String[] args) {

        Greeting greeting =
            new Greeting() {

                public void sayHello() {
                    System.out.println(
                        "Hello!"
                    );
                }
            };

        greeting.sayHello();
    }
}
Output:
Hello!
Anonymous inner classes are useful for short, one-time implementations. We will explore them in more detail in Lesson 25.

Inner Class Comparison

Type Declaration Common Use
Member Inner Class Inside outer class Closely related helper functionality
Static Nested Class Inside outer class with static Independent helper associated with outer class
Local Inner Class Inside a method/block Temporary local functionality
Anonymous Inner Class Class without a name One-time implementation

Real-World Example

Imagine a computer that contains a processor. The processor is strongly related to the computer, so it can be represented using an inner class.

Computer.java 
class Computer {

    class Processor {

        void process() {
            System.out.println(
                "Processing data..."
            );
        }
    }
}

Important Points

  • Classes can be declared inside other classes.
  • Non-static nested classes are called inner classes.
  • Inner classes can access outer class members.
  • Member inner classes require an outer object.
  • Static nested classes do not require an outer object.
  • Local inner classes exist only within their method/block.
  • Anonymous classes do not have a class name.

Lesson Summary

Inner classes allow Java programmers to place closely related classes together. They can improve organization and encapsulation and can directly access members of their outer class.


Java provides member inner classes, static nested classes, local inner classes, and anonymous inner classes. Each type is useful for a different programming situation.
