What is a Method?

A method is a block of code that performs a specific task. Methods help us organize programs and reuse code.

💡 Simple Example

If you need to print a welcome message many times, you can create one method and call it whenever needed.

Creating a Method

A simple Java method can be created inside a class.

MethodExample.java 
static void welcome() {

    System.out.println("Welcome to Java!");

}
Remember:

The method above is named welcome. It does not return a value, so we use void.

Calling a Method

Creating a method does not execute it. We need to call the method.

CallingMethod.java 
class Main {

    static void welcome() {

        System.out.println("Welcome to Java!");

    }


    public static void main(String[] args) {

        welcome();

    }

}
OUTPUT

Welcome to Java!

Method Parameters

Parameters allow us to send values into a method.

Parameter.java 
static void greet(String name) {

    System.out.println("Hello " + name);

}


public static void main(String[] args) {

    greet("Keerthana");

}
OUTPUT

Hello Keerthana

Multiple Parameters

A method can have more than one parameter.

MultipleParameters.java 
static void add(int a, int b) {

    System.out.println(a + b);

}


public static void main(String[] args) {

    add(10, 20);

}
OUTPUT

30

Return Value

A method can return a value using the return keyword.

ReturnValue.java 
static int add(int a, int b) {

    return a + b;

}


public static void main(String[] args) {

    int result = add(10, 20);

    System.out.println(result);

}
OUTPUT

30

void Method

A method with the keyword void does not return a value.

VoidMethod.java 
static void display() {

    System.out.println("Hello Java");

}
💡 Remember:

void means the method does not return a value.

Method Syntax

Syntax 
static returnType methodName(parameters) {

    // method body

    return value;

}
Part Meaning
static Allows the method to be called without creating an object.
returnType Type of value returned by the method.
methodName Name of the method.
parameters Values received by the method.
return Sends a value back to the caller.

Practical Example

Here is a simple calculator using separate methods.

Calculator.java 
class Calculator {

    static int add(int a, int b) {

        return a + b;

    }


    static int multiply(int a, int b) {

        return a * b;

    }


    public static void main(String[] args) {

        System.out.println(add(10, 20));

        System.out.println(multiply(5, 4));

    }

}
OUTPUT

30
20
