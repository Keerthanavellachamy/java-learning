What is a Loop?

A loop is used when we need to execute the same block of code repeatedly.

💡 Simple Example

Instead of writing System.out.println("Hello"); five times, we can use a loop to print it five times.

for Loop

The for loop is commonly used when we know how many times we want to repeat a block of code.

ForLoop.java 
for (int i = 1;
     i <= 5;
     i++) {

    System.out.println(i);

}
OUTPUT

1
2
3
4
5

for Loop Structure

Structure 
for (
    initialization;
    condition;
    update
) {

    // code to repeat

}
Remember:

Initialization runs first, condition is checked before every iteration, and update changes the loop variable.

while Loop

A while loop repeats a block of code as long as the given condition remains true.

WhileLoop.java 
int i = 1;

while (i <= 5) {

    System.out.println(i);

    i++;

}
OUTPUT

1
2
3
4
5

do-while Loop

The do-while loop executes the code first and checks the condition afterward. Therefore, it executes at least once.

DoWhile.java 
int i = 1;

do {

    System.out.println(i);

    i++;

} while (i <= 5);
OUTPUT

1
2
3
4
5

break Statement

The break statement immediately stops the loop.

Break.java 
for (int i = 1;
     i <= 5;
     i++) {

    if (i == 3) {

        break;

    }

    System.out.println(i);

}
OUTPUT

1
2

continue Statement

The continue statement skips the current iteration and moves to the next iteration of the loop.

Continue.java 
for (int i = 1;
     i <= 5;
     i++) {

    if (i == 3) {

        continue;

    }

    System.out.println(i);

}
OUTPUT

1
2
4
5

Nested Loops

A nested loop means placing one loop inside another loop. It is commonly used for patterns and tables.

NestedLoop.java 
for (int i = 1;
     i <= 3;
     i++) {

    for (int j = 1;
         j <= 3;
         j++) {

        System.out.print(i + " ");

    }

    System.out.println();

}
OUTPUT

1 1 1
2 2 2
3 3 3

Types of Loops

Loop When to Use Condition Check
for Known number of repetitions Before execution
while Unknown number of repetitions Before execution
do-while Code must execute at least once After execution
