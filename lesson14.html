Dynamic Method Dispatch

Learn how Java decides at runtime which overridden method should execute when a parent class reference points to a child class object.

Runtime Method Selection

What is Dynamic Method Dispatch?

Dynamic Method Dispatch is the mechanism by which Java selects an overridden method at runtime.

It happens when a parent class reference is used to refer to an object of a child class.

Simple idea:

Parent Reference → Child Object → Overridden Method

Basic Example

class Animal {

    void sound() {
        System.out.println("Animal sound");
    }
}

class Dog extends Animal {

    @Override
    void sound() {
        System.out.println("Dog barks");
    }
}

public class Main {

    public static void main(String[] args) {

        Animal animal = new Dog();

        animal.sound();
    }
}
Dog barks
Why?
The reference is Animal, but the actual object is Dog. Java therefore executes the overridden Dog.sound() method.

How Dynamic Dispatch Works

Animal Reference
→
Dog Object
→
sound()
→
Dog.sound()

The method is selected based on the actual object, not only on the reference type.

Parent Reference

A parent class reference can store the reference of a child class object. 

Animal animal;

animal = new Dog();

animal.sound();
Reference Type: Animal
Actual Object: Dog

Different Child Objects

The same parent reference can point to different child objects at different times. 

Animal animal;

animal = new Dog();
animal.sound();

animal = new Cat();
animal.sound();
Dog barks Cat meows

Complete Example

class Animal {

    void sound() {
        System.out.println("Animal makes a sound");
    }
}

class Dog extends Animal {

    @Override
    void sound() {
        System.out.println("Dog barks");
    }
}

class Cat extends Animal {

    @Override
    void sound() {
        System.out.println("Cat meows");
    }
}

class Cow extends Animal {

    @Override
    void sound() {
        System.out.println("Cow moos");
    }
}

public class Main {

    public static void main(String[] args) {

        Animal animal;

        animal = new Dog();
        animal.sound();

        animal = new Cat();
        animal.sound();

        animal = new Cow();
        animal.sound();
    }
}
Dog barks Cat meows Cow moos

Runtime Decision

Java determines the method implementation based on the actual object created at runtime.

Example:

Animal a = new Dog();

Runtime object → Dog
Executed method → Dog.sound()

Important Note

Dynamic method dispatch applies to overridden instance methods.

Static methods are not overridden in the same way; they are associated with the class.

Dynamic Dispatch and Upcasting

Assigning a child object to a parent class reference is commonly called upcasting. 

Dog dog = new Dog();

Animal animal = dog;

animal.sound();
Upcasting: Child object → Parent reference

Advantages

  • Supports runtime polymorphism.
  • Makes code flexible and extensible.
  • Allows one parent reference to work with many child classes.
  • Reduces dependency on specific child classes.
  • Supports reusable object-oriented designs.

Important Points

  • It works with inheritance.
  • The child class must override the parent method.
  • The reference can be of the parent type.
  • The actual object determines the overridden method.
  • The decision happens at runtime.

Method Overloading vs Dynamic Dispatch

Feature Method Overloading Dynamic Method Dispatch
Type Compile-time polymorphism Run-time polymorphism
Method Same name, different parameters Overridden method
Inheritance Not required Required
Decision Compile time Runtime

Lesson Summary

Dynamic Method Dispatch allows Java to choose an overridden method at runtime based on the actual object rather than only the reference type.

  • Parent reference can point to child object.
  • Child methods can override parent methods.
  • The actual object decides which method executes.
  • It is the foundation of runtime polymorphism.
  • It commonly works together with upcasting.
