What is an Abstract Class?

An abstract class is a class declared using the abstract keyword. It is designed to be inherited by other classes rather than directly instantiated.

Simple idea:

Abstract class = Common features + Incomplete behavior

It is useful when several classes have common properties and methods, but some behavior needs to be implemented differently by each child class.

Basic Syntax

abstract class ClassName {

    // abstract method
    abstract void methodName();

    // normal method
    void display() {
        System.out.println("Hello");
    }
}

Abstract Method

An abstract method is declared without a body. It tells the child class what behavior must be provided. 

abstract void sound();
Rule: A concrete child class must implement the abstract method.

Concrete Method

A normal method inside an abstract class is called a concrete method. It contains a method body. 

void sleep() {
    System.out.println("Animal is sleeping");
}

Abstract Class Example

abstract class Animal {

    abstract void sound();

    void sleep() {
        System.out.println("Animal is sleeping");
    }
}

class Dog extends Animal {

    @Override
    void sound() {
        System.out.println("Dog barks");
    }
}

public class Main {

    public static void main(String[] args) {

        Dog dog = new Dog();

        dog.sound();
        dog.sleep();
    }
}
Dog barks Animal is sleeping

Features of Abstract Classes

  • Can contain abstract methods.
  • Can contain normal methods.
  • Can contain instance variables.
  • Can contain static variables.
  • Can have constructors.
  • Can contain static methods.
  • Cannot be instantiated directly.

Variables in Abstract Classes

Abstract classes can contain variables just like normal classes. 

abstract class Animal {

    String name;

    abstract void sound();
}

Constructor in Abstract Class

Yes, an abstract class can have a constructor. The constructor runs when a child-class object is created. 

abstract class Animal {

    Animal() {
        System.out.println("Animal constructor");
    }

    abstract void sound();
}

class Dog extends Animal {

    Dog() {
        System.out.println("Dog constructor");
    }

    @Override
    void sound() {
        System.out.println("Dog barks");
    }
}

public class Main {

    public static void main(String[] args) {

        Dog dog = new Dog();

        dog.sound();
    }
}
Animal constructor Dog constructor Dog barks
Remember: When a Dog object is created, the Animal constructor executes first, followed by the Dog constructor.

Static Methods

An abstract class can contain static methods because static methods belong to the class rather than to an object. 

abstract class Animal {

    static void info() {
        System.out.println("Animals are living beings");
    }

    abstract void sound();
}

Final Methods

An abstract class can also contain final methods. A final method cannot be overridden by a child class. 

abstract class Animal {

    final void eat() {
        System.out.println("Animal eats");
    }

    abstract void sound();
}

Abstract Class and Inheritance

Abstract classes are commonly used as parent classes. Child classes inherit their common properties and methods and provide implementations for abstract methods. 

abstract class Vehicle {

    void stop() {
        System.out.println("Vehicle stopped");
    }

    abstract void start();
}

class Car extends Vehicle {

    @Override
    void start() {
        System.out.println("Car starts");
    }
}

Multiple Child Classes

One abstract class can have multiple child classes. Each child can provide its own implementation. 

abstract class Shape {

    abstract void draw();
}

class Circle extends Shape {

    @Override
    void draw() {
        System.out.println("Drawing Circle");
    }
}

class Rectangle extends Shape {

    @Override
    void draw() {
        System.out.println("Drawing Rectangle");
    }
}
Drawing Circle Drawing Rectangle

Abstract Class vs Interface

Feature Abstract Class Interface
Keyword abstract class interface
Normal methods Yes Yes, through supported interface methods
Abstract methods Yes Yes
Constructor Yes No
Instance variables Yes Not as normal instance fields
Inheritance A class extends one class A class can implement multiple interfaces

When to Use Abstract Classes?

  • When classes share common code.
  • When classes belong to the same family.
  • When you need constructors.
  • When you need common fields.
  • When some behavior is common and some is different.

Example: Employees

Different employees may have different job roles, but all employees can share common information.

Common: Name, ID, attendance

Different: Work performed by each role

Important Rules

  1. An abstract class must use the abstract keyword.
  2. An abstract class cannot be instantiated directly.
  3. An abstract class can have constructors.
  4. An abstract class can contain fields.
  5. An abstract class can contain normal methods.
  6. An abstract class can contain abstract methods.
  7. A concrete child class must implement all inherited abstract methods.
  8. An abstract class can contain static and final methods.
  9. An abstract class can be extended by another abstract class.

Lesson Summary

Abstract classes provide a common structure for related classes while allowing child classes to implement specialized behavior.

  • Abstract classes are declared using abstract.
  • They cannot be instantiated directly.
  • They can contain abstract and concrete methods.
  • They can contain constructors and variables.
  • Child classes inherit the common functionality.
  • Concrete child classes must implement abstract methods.
  • Abstract classes are useful for partial abstraction.
