Anonymous Classes

What is an Anonymous Class?

An anonymous class is a class that does not have a name. It is declared and instantiated at the same time.

Anonymous classes are mainly useful when you need a small, one-time implementation of a class, abstract class, or interface.

Why Use Anonymous Classes?

  • Useful for one-time implementations.
  • Reduces the need to create a separate class.
  • Useful when implementing an interface quickly.
  • Can override methods immediately.
  • Commonly used with event handling and callbacks.

Basic Syntax

The basic structure of an anonymous class looks like this:

Syntax.java 
Type object = new Type() {

    // Override or implement methods here

};
Notice the semicolon ; after the closing curly brace. The anonymous class is created as part of an object expression.

Anonymous Class with Interface

One of the most common uses is implementing an interface without creating a separate class.

Main.java 
interface Greeting {

    void sayHello();
}

public class Main {

    public static void main(String[] args) {

        Greeting greeting =
            new Greeting() {

                public void sayHello() {

                    System.out.println(
                        "Hello from Java!"
                    );
                }
            };

        greeting.sayHello();
    }
}
Output:
Hello from Java!

How It Works

  1. Define an interface or class.
  2. Use the new keyword.
  3. Open curly braces.
  4. Implement or override the required methods.
  5. Close the braces with a semicolon.

Normal Class vs Anonymous Class

A normal class has a name and can be reused. An anonymous class has no name and is generally created for a single use.

Normal class: Better when the implementation is reused in multiple places.

Anonymous class: Useful for short, one-time implementations.

Using a Normal Class

Example.java 
class Animal {

    void sound() {
        System.out.println(
            "Animal sound"
        );
    }
}

Animal a = new Animal();

a.sound();

Anonymous Class with Method Override

An anonymous class can extend a normal class and override its methods.

Example.java 
class Animal {

    void sound() {
        System.out.println(
            "Animal sound"
        );
    }
}

Animal dog = new Animal() {

    @Override
    void sound() {

        System.out.println(
            "Dog barks"
        );
    }
};

dog.sound();
Output:
Dog barks

Anonymous Class with Abstract Class

Anonymous classes can also provide an implementation for an abstract class.

Main.java 
abstract class Shape {

    abstract void draw();
}

Shape shape = new Shape() {

    @Override
    void draw() {

        System.out.println(
            "Drawing a circle"
        );
    }
};

shape.draw();
Output:
Drawing a circle

Multiple Methods

An anonymous class can implement multiple methods defined by its parent type.

Example.java 
interface Calculator {

    void add();

    void subtract();
}

Calculator c = new Calculator() {

    public void add() {
        System.out.println("Addition");
    }

    public void subtract() {
        System.out.println("Subtraction");
    }
};

Using Variables

Anonymous classes can use variables from the surrounding context when those local variables are final or effectively final.

Example.java 
final int number = 10;

Runnable task = new Runnable() {

    public void run() {

        System.out.println(number);
    }
};

task.run();
Output:
10

Anonymous Class with Runnable

The Runnable interface is a common example of anonymous classes.

Main.java 
Runnable task = new Runnable() {

    @Override
    public void run() {

        System.out.println(
            "Task is running"
        );
    }
};

task.run();
Output:
Task is running

Anonymous Class vs Lambda

When an interface is a functional interface, Java often allows a shorter lambda expression instead of an anonymous class.

Anonymous Class

Anonymous.java 
Runnable task = new Runnable() {

    public void run() {
        System.out.println(
            "Hello"
        );
    }
};

Lambda Expression

Lambda.java 
Runnable task =
    () -> System.out.println("Hello");
Lambda expressions are shorter, but anonymous classes are still useful when you need more complex class behavior or when working with abstract classes.

Comparison

Feature Normal Class Anonymous Class
Class Name Has a name No name
Reusability Highly reusable Usually one-time use
Code Size Can be larger Useful for short implementations
Object Creation Separate object creation Class and object created together
Common Use General application logic Callbacks and one-time behavior

Advantages

  • Short and convenient for small implementations.
  • No need to create a separate class file.
  • Useful for callbacks.
  • Useful for overriding behavior quickly.

Limitations

  • Cannot be reused easily by name.
  • Large anonymous classes can reduce readability.
  • Cannot define a constructor because it has no name.
  • A separate named class is better for complex behavior.

Important Points

  • An anonymous class has no class name.
  • It is declared and instantiated at the same time.
  • It can extend a class.
  • It can implement an interface.
  • It can override methods.
  • It is generally used for one-time implementations.
  • Functional interfaces can often be implemented using lambdas instead.

Lesson Summary

Anonymous classes are unnamed classes created at the point where they are needed. They are useful for implementing an interface or extending a class for a single use.


They are especially useful for short implementations, callbacks, and method overriding. For larger reusable functionality, a normal named class is usually easier to maintain.
