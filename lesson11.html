The super Keyword

Learn how to use the super keyword to access parent class variables, methods, and constructors from a child class.

super Parent Access

What is the super Keyword?

The super keyword in Java is used inside a child class to refer to its immediate parent class.

It is mainly used to access:

  • Parent class variables
  • Parent class methods
  • Parent class constructors
Remember:
this refers to the current class, while super refers to the immediate parent class.

Why Use super?

The super keyword is useful when a child class needs to work with members inherited from its parent.

  • Resolve variable name conflicts
  • Call an overridden parent method
  • Call a parent constructor
  • Reuse existing parent class functionality

Accessing Parent Variable

When both parent and child classes have variables with the same name, super can be used to access the parent variable. 

class Animal {
    String name = "Animal";
}

class Dog extends Animal {

    String name = "Dog";

    void showNames() {
        System.out.println(name);
        System.out.println(super.name);
    }
}
Dog Animal
Explanation:
name refers to the child class variable, while super.name refers to the parent class variable.

Calling Parent Class Method

When a child class overrides a parent method, super.methodName() can be used to call the original parent implementation. 

class Animal {

    void sound() {
        System.out.println("Animal makes a sound");
    }
}

class Dog extends Animal {

    @Override
    void sound() {

        super.sound();

        System.out.println("Dog barks");
    }
}
Animal makes a sound Dog barks

Calling Parent Constructor

The super() statement is used to call the constructor of the immediate parent class. 

class Animal {

    Animal() {
        System.out.println("Animal constructor");
    }
}

class Dog extends Animal {

    Dog() {

        super();

        System.out.println("Dog constructor");
    }
}
Animal constructor Dog constructor

super() Rules

  • super() must be the first statement inside a constructor.
  • It calls the immediate parent constructor.
  • If no constructor call is written, Java may insert super() automatically.
  • The parent constructor executes before the child constructor.

Constructor Execution Order

When an object of a child class is created, the parent constructor runs first.

Order:

Parent Constructor → Child Constructor

Real-World Example

Imagine a Vehicle class and a Car class. The car inherits common vehicle information but can also add its own details. 

class Vehicle {

    String brand = "Toyota";

    void display() {
        System.out.println("This is a vehicle");
    }
}

class Car extends Vehicle {

    void showDetails() {

        System.out.println(super.brand);

        super.display();

        System.out.println("This is a car");
    }
}

public class Main {

    public static void main(String[] args) {

        Car car = new Car();

        car.showDetails();
    }
}
Toyota This is a vehicle This is a car

Important Points

  • super refers to the immediate parent class.
  • super.variable accesses a parent variable.
  • super.method() calls a parent method.
  • super() calls a parent constructor.
  • super() must be the first statement in a constructor.
  • It is commonly used with inheritance and method overriding.

Common Mistakes

  • Using super() outside a constructor.
  • Writing super() after another constructor statement.
  • Trying to use super to access a static context incorrectly.
  • Confusing super with this.

Lesson Summary

The super keyword is an important part of inheritance in Java. It allows a child class to access members of its immediate parent class.

  • super.variable → parent variable
  • super.method() → parent method
  • super() → parent constructor
