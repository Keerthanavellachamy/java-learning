What is an Array?

An array is a collection of values of the same data type stored under one variable name.

💡 Simple Example

Instead of creating five separate variables for five marks, we can store all five marks inside one array.

Creating an Array

There are different ways to create an array in Java.

ArrayExample.java 
int[] numbers = {10, 20, 30, 40, 50};
Remember:

All elements in this array are integers.

Array Index

Array indexing starts from 0, not 1.

Index Value
0 10
1 20
2 30
3 40
4 50
⚠️ Important

The first element is always at index 0.

Accessing Array Elements

We can access an element using its index number.

AccessArray.java 
int[] numbers = {10, 20, 30};

System.out.println(numbers[0]);
System.out.println(numbers[1]);
System.out.println(numbers[2]);
OUTPUT

10
20
30

Updating an Array Element

We can change the value of an array element by using its index.

UpdateArray.java 
int[] numbers = {10, 20, 30};

numbers[1] = 50;

System.out.println(numbers[1]);
OUTPUT

50

Loop Through an Array

A for loop can be used to access every element of an array.

LoopArray.java 
int[] numbers = {10, 20, 30, 40};

for (int i = 0;
     i < numbers.length;
     i++) {

    System.out.println(numbers[i]);

}
OUTPUT

10
20
30
40

Array length

The length property tells us how many elements are present in an array.

Length.java 
int[] numbers = {10, 20, 30, 40};

System.out.println(numbers.length);
OUTPUT

4

Two-Dimensional Array

A two-dimensional array stores data in rows and columns. It is similar to a table or matrix.

TwoDArray.java 
int[][] numbers = {

    {1, 2},
    {3, 4}

};

System.out.println(numbers[0][1]);
OUTPUT

2

Types of Arrays

Type Example Use
1D Array int[] numbers Store a list of values
2D Array int[][] numbers Store rows and columns
