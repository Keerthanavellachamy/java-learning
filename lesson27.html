The Object Class

Learn about Java's most important built-in class, the Object class, and understand methods such as toString(), equals(), and hashCode().

What is the Object Class?

The Object class is the root class of the Java class hierarchy. Every Java class directly or indirectly inherits from Object.

This means every Java object automatically gets access to important methods defined by the Object class.

Object Class and Inheritance

If a class does not explicitly extend another class, Java automatically makes it a subclass of Object.

Example.java 
class Student {

    // Automatically extends Object
}

Conceptually, Java treats it like:

Example.java 
class Student
    extends Object {

}

Important Object Class Methods

Method Purpose
toString() Returns a string representation of an object.
equals() Compares objects according to the equality logic.
hashCode() Returns a hash code value for an object.
getClass() Returns information about the object's runtime class.
clone() Used for creating a copy of an object when supported.
finalize() Legacy method associated with object finalization; deprecated in modern Java.

toString() Method

The toString() method returns a string representation of an object.

If you do not override it, the default implementation usually produces a value containing the class name and a hash-related identifier.

Student.java 
class Student {

    String name = "Keerthana";
}

Student student = new Student();

System.out.println(student.toString());
Instead of relying on the default representation, we can override toString() to return meaningful information.

Overriding toString()

Student.java 
class Student {

    String name = "Keerthana";

    @Override
    public String toString() {

        return "Student: " + name;
    }
}

toString() Output

Main.java 
Student student =
    new Student();

System.out.println(student);
Output:
Student: Keerthana
When an object is passed to println(), Java can call its toString() method automatically.

equals() Method

The equals() method is used to compare objects for logical equality.

The default Object implementation compares object references. Many classes override equals() to compare their actual data.

Student.java 
class Student {

    String name;

    Student(String name) {
        this.name = name;
    }

    @Override
    public boolean equals(Object obj) {

        Student other =
            (Student) obj;

        return name.equals(other.name);
    }
}

equals() Example

Main.java 
Student s1 =
    new Student("Keerthana");

Student s2 =
    new Student("Keerthana");

System.out.println(
    s1.equals(s2)
);
Output:
true

== vs equals()

  • == compares references when used with objects.
  • equals() can compare logical content.
  • Classes can override equals() to define their own equality rules.
For custom classes, if you override equals(), you should generally also override hashCode().

hashCode() Method

The hashCode() method returns an integer hash value representing the object.

Example.java 
Student student =
    new Student("Keerthana");

System.out.println(
    student.hashCode()
);
Hash codes are especially important when objects are stored in hash-based collections such as HashMap and HashSet.

equals() and hashCode() Contract

Java follows an important rule:

If two objects are equal according to equals(), they must return the same hashCode().

However, two objects having the same hash code do not necessarily have to be equal.

getClass()

The getClass() method returns the runtime class of an object.

Main.java 
Student student =
    new Student("Keerthana");

System.out.println(
    student.getClass().getName()
);
Output:
Student

Object Reference

Because every class inherits from Object, an Object reference can hold a reference to an object of any class.

Example.java 
Object obj =
    new Student("Keerthana");
This is an example of upcasting because Student is a subclass of Object.

Using Object Methods

Main.java 
Object obj =
    new Student("Keerthana");

System.out.println(obj.toString());

System.out.println(obj.getClass());

System.out.println(obj.hashCode());

These methods are available because Student inherits them from Object.

clone() Method

The clone() method is associated with creating a copy of an object.

Cloning has special rules and is not always the preferred way to copy objects. Modern Java code often uses copy constructors or other explicit copying techniques.

finalize()

The finalize() method was historically associated with cleanup before garbage collection.

Important: finalize() is deprecated and should not be used in modern Java applications.

Object Class Methods Summary

Method Use
toString() Readable string representation
equals() Logical object comparison
hashCode() Hash value for the object
getClass() Runtime class information
clone() Object copying when supported
finalize() Legacy cleanup mechanism; deprecated

Important Points

  • Object is the root class of Java's class hierarchy.
  • Every class directly or indirectly extends Object.
  • toString() provides a string representation.
  • equals() is used for logical equality.
  • hashCode() is important for hash-based collections.
  • getClass() provides runtime class information.
  • finalize() is deprecated in modern Java.

Lesson Summary

The Object class is the root of the Java class hierarchy. Because every class inherits from Object, every object has access to important methods such as toString(), equals(), hashCode(), and getClass().


Understanding these methods is essential for writing well-designed Java classes and working effectively with collections and object-oriented programs.
