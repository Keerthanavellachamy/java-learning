What is Java?

Java is a high-level, object-oriented programming language. It was designed to be simple, secure, reliable and platform independent.

Java is commonly used for web applications, enterprise applications, desktop software, Android development and many other systems.

Features of Java

🎯

Simple

Easy syntax for beginners to understand.

🧩

Object-Oriented

Programs are organized using classes and objects.

🌎

Platform Independent

Java programs can run on different platforms.

🔐

Secure

Java provides several security features.

⚡

Robust

Java is designed to handle errors reliably.

📦

Portable

Java applications can move between systems.

Your First Java Program

Main.java 
class Main {

    public static void main(String[] args) {

        System.out.println("Hello World");

    }

}

Understand the Code

class Main creates a class named Main.

public static void main() is the main method where Java starts executing the program.

System.out.println() displays text on the screen.

💡 Remember

The main() method is the entry point of a basic Java application.
