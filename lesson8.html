What is a String?

A String is a sequence of characters used to store text. In Java, String is a class and text is written inside double quotation marks.

StringExample.java 
String name = "Keerthana";

String college = "Meenakshi College of Engineering";
💡 Remember:

Strings use double quotes, such as "Hello Java".

Creating a String

The most common way to create a String is by assigning text to a String variable.

CreateString.java 
String message = "Welcome to Java!";

System.out.println(message);
OUTPUT

Welcome to Java!

String Concatenation

We can join two or more strings using the + operator.

Concatenation.java 
String firstName = "Keerthana";

String lastName = "V";

String fullName = firstName + " " + lastName;

System.out.println(fullName);
OUTPUT

Keerthana V

String length()

The length() method returns the number of characters in a string.

Length.java 
String name = "Java";

int length = name.length();

System.out.println(length);
OUTPUT

4

💡 Important:

length() counts all characters, including spaces.

Changing Case

Java provides methods to convert strings to uppercase or lowercase.

Case.java 
String text = "Java Programming";

System.out.println(text.toUpperCase());

System.out.println(text.toLowerCase());
OUTPUT

JAVA PROGRAMMING
java programming

charAt()

The charAt() method returns the character at a specific index.

CharAt.java 
String language = "Java";

System.out.println(language.charAt(0));

System.out.println(language.charAt(2));
OUTPUT

J
v

Remember:

String indexing starts from 0.

equals()

The equals() method is used to compare the contents of two strings.

Compare.java 
String a = "Java";

String b = "Java";

boolean result = a.equals(b);

System.out.println(result);
OUTPUT

true

contains()

The contains() method checks whether a string contains a particular sequence of characters.

Contains.java 
String text = "I am learning Java";

System.out.println(text.contains("Java"));
OUTPUT

true

substring()

The substring() method is used to extract a part of a string.

Substring.java 
String text = "Java Programming";

System.out.println(text.substring(0, 4));
OUTPUT

Java

💡 Remember:

The starting index is included, but the ending index is not included.

Common String Methods

Method Purpose Example
length() Finds the number of characters. text.length()
toUpperCase() Converts text to uppercase. text.toUpperCase()
toLowerCase() Converts text to lowercase. text.toLowerCase()
charAt() Gets a character at an index. text.charAt(0)
equals() Compares two strings. a.equals(b)
contains() Checks whether text exists. text.contains("Java")
substring() Extracts part of a string. text.substring(0, 4)
trim() Removes leading and trailing spaces. text.trim()

Practical Example

Let's create a simple program that works with a student's name and course.

Student.java 
class Student {

    public static void main(String[] args) {

        String name = "Keerthana";

        String course = "Java";

        System.out.println("Student: " + name);

        System.out.println("Course: " + course);

        System.out.println("Name Length: " + name.length());

    }

}
OUTPUT

Student: Keerthana
Course: Java
Name Length: 8
