What is a Variable?

A variable is a named storage location used to hold a value in a Java program.

Think of a variable like a box. The box has a name and it stores some information inside it.

Variable Syntax

Variable.java 
dataType variableName = value;
💡 Example

int age = 20;

Here, int is the data type, age is the variable name, and 20 is the value.

Common Data Types

Data Type Used For Example
int Whole numbers 20
double Decimal numbers 85.5
float Decimal numbers 10.5f
char Single character 'A'
boolean True or false true
String Text "Java"

Example Program

Main.java 
class Main {

    public static void main(String[] args) {

        String name =
            "Keerthana";

        int age =
            20;

        double mark =
            85.5;

        char grade =
            'A';

        boolean student =
            true;

        System.out.println(name);
        System.out.println(age);
        System.out.println(mark);
        System.out.println(grade);
        System.out.println(student);

    }

}

Important Points

💡 Remember

Java is a strongly typed language. This means every variable must have a data type.

⚡ Example

int age = 20; is valid because 20 is a whole number.

⚠️ Be Careful

Java is case-sensitive. For example, Age and age are different variables.
